# README-auto-update

This is the replication for paper titled "Does My README File Need To Be Updated? Exploring LLM-Based README Maintenance".

## Folder walkthrough

`agent_model` includes the agent implementation, while `pipeline_mode` includes the static version encompassing each component. Please refer to the `prompts.py` under each folder for the design. In folder `failure_analysis` we attached an excel spreadsheet for our qualitative analysis.
